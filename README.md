# Smart Housing Advisor

An interactive housing affordability and market trends explorer built with Python. Users input their financial profile and get personalized city recommendations, market trend visualizations, and buyer-condition insights powered by real Redfin data.

## Features

- Estimates max home budget based on income, down payment, and credit score
- Filters and ranks affordable cities from a national Redfin housing dataset
- Visualizes median sale price, inventory, and days-on-market trends over time using Matplotlib, Seaborn, and Plotly
- Generates automated market summaries identifying buyer-favorable conditions

## Technologies

- Python, Pandas, NumPy
- Matplotlib, Seaborn, Plotly
- Jupyter Notebook
- Data source: [Redfin Data Center](https://www.redfin.com/news/data-center)
